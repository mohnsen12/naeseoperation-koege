# Patientvideo om næseskillevægsoperation i Køge

Statisk webside til GitHub Pages. `index.html` viser videoen med danske undertekster og link til manuskriptet. Siden kan offentliggøres fra roden af et offentligt GitHub-repository via Settings → Pages → Deploy from a branch.

Videoen er et udkast til faglig gennemgang. Afdelingen bør kontrollere indhold, mødested, kontaktoplysninger og lokale instrukser før patientbrug. Patientens individuelle indkaldelse og udskrivelsesvejledning er gældende.
